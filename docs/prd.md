 # PRD：个人网站
 
 ## 1. 目标与定位
 
 **目标访问者**：共同爱好者。他们最先寻找博客里输出的原创内容。
 
 **希望访客记住**：我的基本信息（名字、专业方向、技能），对主页内容有清晰印象。
 
 ## 2. 内容范围
 
 本期必须包含：
 
 - Hero —— 首页顶部欢迎区（站点名称 + 视觉标识）
 - About —— 个人简介
 - Skills —— 技能列表（待补充）
 - Projects —— 项目展示（当前作业链接）
 - Contact —— 联系方式（GitHub 主页）
 - 博客文章 —— 图文结合的博客（缩略图 + 摘要 + 全文）
 
 ## 3. 本期不做什么
 
 - 不做用户登录系统
 - 不做数据库存储
 - 不做支付功能
 - 不做复杂后台管理
 - 不采集访客隐私数据
 
 ## 4. 验收标准
 
 - [ ] 页面可通过 GitHub Pages 公开访问
 - [ ] 所有展示内容真实有效
 - [ ] 手机端可正常阅读、导航折叠
 - [ ] 所有链接可点击、跳转正确
 - [ ] 过程材料完整（PRD / Design / Checklist / 报告 / 截图）
 
 ## 5. 隐私边界
 
 仓库中不包含以下信息：
 
 - 密码与登录凭据
 - API Key 与 Token
 - 课程邀请码
 - `.env` 文件
 - 私人反馈内容
 - 手机号、住址、身份证件
