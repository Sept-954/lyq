# 最终报告：L 的个人空间

## 项目定位

个人网站与博客，面向共同爱好者。

## 模板选择

- **模板**：[Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes)
- **使用方式**：静态页面（.nojekyll）

## 主要修改

- 首页改为落地页，含 Hero / About / Skills / Projects / Contact
- 导航栏深蓝底白字
- 圆形头像、附件文档区、分类描述区

## AI 参与

| 阶段 | AI 协助 |
|------|--------|
| 需求分析 | 阅读作业要求，制定计划 |
| 页面开发 | 生成首页五个区块、文章列表等 |
