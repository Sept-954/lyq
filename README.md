# L 的个人空间

基于 Minimal Mistakes Jekyll 主题的个人网站与博客。

## 模板

- **模板**：[Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes)
- **使用方式**：remote_theme（`mmistakes/minimal-mistakes@4.28.0`）

## 主要修改

- 将首页从默认博客列表改为 splash 全宽落地页，包含 Hero、About、Skills、Projects、Contact 五个区块
- 配置 `air` 皮肤与中文 locale
- 精简导航栏为首页 / 文章 / 分类 / 标签
- 添加个人资料、占位头像和博客缩略图

## 本地预览

需要 Ruby + Bundler 环境：

```bash
bundle install
bundle exec jekyll serve
```

然后访问 http://localhost:4000/lyq/
